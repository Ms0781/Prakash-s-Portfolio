Design Process

How I Craft UI/UX

01. Discovery 02. Wireframing 03. Design System 04. Prototyping 05. Dev Handoff

01. Research & User Journey

Stakeholder interviews, clinical persona mapping, and empathy mapping to uncover real pain points and structure intuitive information architecture.

02. Wireframing & UX Flows

Low-to-high fidelity wireframes and user flow mapping in Figma to test navigation logic, data hierarchy, and remove user friction early.

03. Design System & UI Kit

Building scalable atomic component libraries with Figma Auto Layout, responsive data grids, typography scales, and unified design tokens.

04. Prototyping & Dev Handoff

Interactive clickable prototypes validated with real users, paired with pixel-perfect Figma specs and tokens for 40% faster developer handoff.
